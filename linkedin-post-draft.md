I just submitted my first Chrome extension to the Google Web Store. 🚀

And here's the crazy part — I'm an **incoming UC Berkeley freshman ('30)**, and I didn't write most of the code.

**LinkedIn AI Assistant** reads any LinkedIn profile and generates 4 personalized connection message styles (Professional / Casual / Enthusiastic / Concise). Copy, edit, regenerate. No auto-send, no data collection.

I used **vibe coding** — AI handled React + TypeScript + Cloudflare Workers backend. I handled product decisions, UX design, privacy architecture, quality control.

Zero to shippable Chrome extension in ~2 weeks.

🔗 **GitHub (open source):** https://github.com/stevenli2007-del/Linkedin-AI-Assistant
→ Clone it, try it, or just read through the code. Everything is public.

**If you want to give it a try — or if you have feedback, ideas, or just want to chat about AI-assisted building — hit me up. Let's connect. 👋**

(Yes, I'll probably use my own extension to write your connection message. Meta. 🔄)

## What I Learned

1️⃣ **AI amplifies, doesn't replace.** Every line was generated by AI. Every decision was mine.

2️⃣ **Done > perfect.** Wrong screenshot sizes? Fixed. Windows backslashes in my ZIP? Repacked. Category mislabeled? Corrected on the spot. You learn more from shipping than from polishing.

3️⃣ **Privacy is non-negotiable.** No auto-send, minimal data usage, clear policy. Users trust tools that respect them.

## 我的收获

1️⃣ **AI 是放大器，不是替代品。** 每一行代码都是 AI 写的，但每个决定都是我的。
2️⃣ **完成 > 完美。** 截图尺寸错了？改。ZIP 里混进了 Windows 反斜杠？重打包。分类填错了？当场修正。从发布中学到的比从打磨中多得多。
3️⃣ **隐私没有商量余地。** 不自动发送、最少数据收集、清晰的隐私政策。尊重用户的工具才配被信任。
